# User Stories - Smart Clinic Management System

## Doctor User Stories

1. As a Doctor, I want to log in to the system so that I can access my dashboard securely
2. As a Doctor, I want to view all my patient appointments so that I can manage my schedule effectively
3. As a Doctor, I want to create prescriptions for patients so that I can provide proper medical care
4. As a Doctor, I want to update my available times so that patients can book appointments during my availability
5. As a Doctor, I want to view patient medical history so that I can provide better informed care
6. As a Doctor, I want to update appointment status so that I can track completed consultations
7. As a Doctor, I want to search for patient records so that I can quickly access patient information

---

## Patient User Stories

1. As a Patient, I want to register an account so that I can use the clinic services
2. As a Patient, I want to log in to the system so that I can access my profile and medical information
3. As a Patient, I want to search for doctors by name or specialty so that I can find the right healthcare provider
4. As a Patient, I want to view doctor availability so that I can book appointments at convenient times
5. As a Patient, I want to book appointments with available doctors so that I can receive medical care
6. As a Patient, I want to view my appointment history so that I can track my medical visits
7. As a Patient, I want to view my prescriptions so that I can follow medical instructions properly
8. As a Patient, I want to update my profile information so that my records are current

---

## Admin User Stories

1. As an Admin, I want to log in to the admin portal so that I can manage the system securely
2. As an Admin, I want to add new doctors to the system so that patients have more healthcare options
3. As an Admin, I want to manage doctor profiles so that doctor information is accurate and up-to-date
4. As an Admin, I want to view system reports so that I can monitor clinic operations
5. As an Admin, I want to manage patient accounts so that I can assist users with account issues
6. As an Admin, I want to view all appointments so that I can oversee clinic scheduling
7. As an Admin, I want to deactivate inactive accounts so that the system remains organized
